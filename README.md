# AIR-CRAFT - Military Aviation Marketplace

AIR-CRAFT is a web-based marketplace for military aircraft, allowing users to browse, filter, and purchase various aircraft from different regions.

## Features

- **Global Inventory**: Browse aircraft from the USA, Russia, Europe, India, and China.
- **Filtering**: Easily filter aircraft by country/region.
- **Shopping Cart**: Add aircraft to your cart, view subtotals, and apply discounts for large purchases.
- **Profile Management**: User profile section for account management.
- **Responsive Design**: Optimized for different screen sizes.

## Technologies Used

- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)

## Setup

1. Clone the repository.
2. Open `index.html` in your browser.
